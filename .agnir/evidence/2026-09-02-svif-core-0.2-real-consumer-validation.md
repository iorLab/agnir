The real consumer evidence validates:

1. explicit Core/profile `0.1` → `0.2` consumer migration;
2. same Project identity across multiple logical lineages;
3. selector/ref != logical lineage identity != revision receipt;
4. binding-driven fresh discovery;
5. independent branch-local checkpoints and real divergence;

7. staged integration without target advancement;
8. source continuity as reconciliation input, not target truth;
9. target reconciliation before publication;
