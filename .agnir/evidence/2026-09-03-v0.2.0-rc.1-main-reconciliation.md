## Staged publication protocol

The integration candidate must be a target-first two-parent commit:

- first parent: captured main `f0b2cbd...`;
- second parent: accepted release source `866604c...`;
- tree: accepted release Project/package tree plus reconciled main `AGNIR.yaml`, main State/Next, this Evidence, and Core 0.2 main self-host CI behavior.

The candidate is staged on a temporary integration ref and validated through a PR/CI surface while `main` remains unchanged. Before target publication, both source and target refs must be freshly re-read and still equal the captured receipts. If either moved, discard/reconcile again.

Only after exact candidate-tree conformance succeeds may `main` advance once directly to the candidate commit. The candidate revision itself is the checkpoint receipt; its SHA is intentionally not self-embedded in the content that determines it.
