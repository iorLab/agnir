## Frozen version model

- Repository release SemVer: `0.1.0` (`VERSION`).
- Core compatibility line: `0.1` (`agnir.version`).
- Repository/filesystem profile compatibility line: `repository-filesystem/0.1`.
- Breaking Core semantics require a new Core line; breaking repository/filesystem profile semantics require a new profile line.
- Repository patch releases may make non-breaking clarifications, add compatible conformance pressure, or fix reference tooling without changing those compatibility identifiers.

## Release-readiness review

The release review reconciled the active Core, Discovery contract, repository/filesystem profile, manifest schema, bilingual READMEs, conformance baseline, self-host checker, `AGNIR.yaml`, and repository release metadata.

The review removed two stale predecessor couplings from the active line:

1. the deleted predecessor branch reference was removed from `AGNIR.yaml`;
2. predecessor bootstrap fallback was removed from the active repository/filesystem profile.

Historical PPMP / PPM / Sandminni material remains under `history/` only and is not part of Core semantics, profile compatibility, conformance, or release gating.

## Conformance baseline

The stable suite covers self-hosting cold start, all nine named discovery failure classes, durable non-repository SQLite continuity, external-memory authorization semantics, multi-project isolation, Locator Chain cycle/stale/inconsistency semantics, symlink boundaries, and real Git worktree cold start.

## Known limitation

Real mount-boundary behavior remains explicitly unproven because a real mount-capable test environment has not been available. An ordinary directory is not accepted as substitute evidence. This limitation is documented and is not considered a blocker for Core `0.1` publication.

## Publication boundary

Agnir is release-ready at repository version `0.1.0`. The remaining action is publication itself: create the intended `v0.1.0` tag and/or GitHub Release from a publication commit after explicit authorization. No tag or GitHub Release is claimed by this evidence record.
