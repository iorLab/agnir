# Launch and Adoption Strategy Approval — 2026-09-07

The Principal approved the post-`v1.0.0` Agnir launch/adoption direction and authorized it to be persisted in the Project.

Canonical strategy:

- `adoption/README.md`

Accepted boundaries:

- Agnir leads with the **Project Continuity** category rather than generic “AI memory” positioning.
- `brand/` remains the canonical visual identity/production-asset authority.
- `adoption/` owns launch, positioning, demos, community, design-user and case-study strategy.
- Early success is measured primarily by genuine external fresh-session resumes and repeat use, not GitHub stars.
- Public launch proceeds from launch hygiene → design-user evidence → technical launch → broader distribution.
- Marketing/adoption material does not redefine Agnir Core semantics or reopen satisfied release gates by default.

This is a product/adoption decision, not a Core/profile compatibility change. Stable `v1.0.0`, historical `0.1`/`0.2` compatibility, and published release tags remain unchanged.
