# Product Profile

Version: 2.0.0

Use this profile for product requirements, user problems, prioritization, roadmaps, launch criteria, metrics, and cross-functional feature planning.

Create durable requirements, roadmap, discovery, metrics, or launch artifacts lazily when they add value beyond Core. Storage layout is implementation-specific.

Persist confirmed problem framing, target users, scope changes, prioritization decisions, acceptance/launch criteria, metric definitions, material trade-offs, rollout decisions, and evidence that changes product direction.

Distinguish Proposed ideas from Planned work and Completed implementation from Verified outcomes. Product decisions SHOULD preserve rationale when later reversal would otherwise require expensive rediscovery.
