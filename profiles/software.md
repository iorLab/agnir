# Software Profile

Version: 2.0.0

Use this profile for projects whose durable work centers on source code, systems, infrastructure, testing, deployment, schemas, or implementation.

Create architecture, ADR, testing, deployment, changelog, or equivalent durable artifacts lazily when Core would otherwise become overloaded. Their storage locations are implementation/backend conventions, not protocol requirements.

Persist architecture changes, significant bug root causes, migration/schema strategies, CI or validation changes, deployment topology changes, feature completion/verification, and material dependency or compatibility constraints.

Software claims SHOULD identify verification evidence such as test results, workflow status, builds, deployment confirmation, runtime inspection, commits, PRs, or releases. Implemented is not equivalent to Verified.
