# Core 0.2 Decision Log

## 2026-09-02

- Repository release `v0.2.0` and Core compatibility `0.2` are treated as related but distinct version dimensions.
- Parallel Continuity is being evaluated for Core 0.2 only through backend-neutral semantics; Git branch terminology remains outside Core.
- Core 0.2 acceptance requires both VCS-backed and non-VCS conformance.
- `v1.0.0` is defined as a stability and compatibility commitment, not a feature-count threshold.
