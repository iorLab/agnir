# Agnir Release Milestones

- `v0.1.x`: establish and pressure-test the first stable Core `0.1` + repository/filesystem profile.
- `v0.2.0`: intended next feature release if Parallel Continuity / Continuity Lineage passes the Core 0.2 design and conformance gates; repository release and Core compatibility are versioned separately.
- `v1.0.0`: stability milestone. Publish only when the public Core contract, compatibility/migration discipline, conformance, failure semantics, publication integrity, documentation, and real-world evidence are strong enough to support a durable downstream compatibility commitment.
