# v1.0.0 Readiness Interpretation

Agnir `v1.0.0` is ready only when all required gates in `docs/V1_RELEASE_CRITERIA.md` are satisfied and there is no known open issue that would require a breaking redesign of the current Core contract.

The recommended evidence thresholds may be exceeded or refined as Core 0.2 matures, but they should not be lowered merely to hit a release date.

The key distinction is:

- `v0.x`: the project may still deliberately reshape public contracts as evidence accumulates;
- `v1.0.0`: downstream Projects may reasonably treat the published Core compatibility and migration rules as stable infrastructure.
