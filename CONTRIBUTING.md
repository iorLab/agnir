# Contributing to Agnir

Agnir welcomes bug reports, product ideas, adoption reports, documentation improvements, conformance cases, and compatible implementation work.

- Use the GitHub issue forms for bugs, ideas, and adoption reports.
- For code or specification changes, open a pull request against `main`.
- Preserve the published Core/profile compatibility contracts and immutable release tags.
- Treat `brand/masters/` as visual authority; do not redesign approved identity assets in unrelated changes.
- Contributions intentionally submitted for inclusion are handled under the repository's Apache License 2.0 terms unless explicitly stated otherwise.

Before proposing a semantic change, read `AGNIR.yaml`, `spec/`, the selected profile, and the current `.agnir/` continuity so the change is reconciled against current Project truth rather than inferred from stale chat context.
