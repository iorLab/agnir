# Agnir Release Milestones

- `v0.1.x`: established and pressure-tested the first stable Core `0.1` + repository/filesystem `0.1` profile.
- `v0.2.0`: stable pre-1.0 feature release line for Continuity Lineages. Its acceptance gates are Core `0.2` design, explicit `0.1` → `0.2` migration, materially different VCS and non-VCS backend conformance, fresh install/resume, and real-Project validation. These versioned repository-release gates are separate from the stronger long-term compatibility commitment required for `v1.0.0`.
- `v1.0.0`: stability milestone. Publish only when the public Core contract, compatibility/migration discipline, conformance, failure semantics, publication integrity, documentation, real-world evidence, and release-candidate process are strong enough to support a durable downstream compatibility commitment.
