# Agnir Release Milestones

- `v0.1.x`: establish and pressure-test the first stable Core `0.1` + repository/filesystem profile.
- `v0.2.0`: intended next feature release if Parallel Continuity / Continuity Lineage passes Core `0.2` design, migration, dual-backend conformance, and real-Project validation gates. Repository release and Core compatibility are versioned separately.
- `v1.0.0`: stability milestone. Publish only when the public Core contract, compatibility/migration discipline, conformance, failure semantics, publication integrity, documentation, real-world evidence, and release-candidate process are strong enough to support a durable downstream compatibility commitment.
