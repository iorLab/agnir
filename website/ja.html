不安を先に解消

今の仕事のやり方を変える必要はありません。

特定の Agent にロックインされますか？

いいえ。Agnir の継続性はプロジェクトに属し、特定の Agent、モデル、チャット、実行環境には属しません。

すべてのチャット履歴を保存する必要がありますか？

ありません。Agnir はセッションをまたいで本当に残すべき少量のプロジェクト事実だけを保存し、チャット履歴をプロジェクトの真実にはしません。

Git、IDE、開発フローを置き換えますか？

いいえ。今のツールは今まで通り使えます。Agnir が担当するのは、持続するプロジェクト状態の発見、読み込み、Checkpoint だけです。

また別の不透明なメモリ基盤ですか？

いいえ。次のアクション、意思決定、証拠は読みやすい Markdown としてプロジェクト内に残ります。

最後に概念

Agnir とは？

Agnir は Project Continuity（プロジェクト継続性）プロトコルです。新しい Agent が安全に作業を続けるために必要な少量の持続的なプロジェクト事実を、プロジェクト自身に残すための移植可能な契約です。

現在の状態

02

次のアクション

次に何を、どの順序で行うか。

03

意思決定

次の Agent も守るべき制約と選択。

04

証拠

復元、レビュー、移行、整合を検証できる記録。

ツールをまたぐために設計

Agent を変えても、プロジェクトは変えない。

Agnir Core は Git、GitHub、ファイルシステム、ChatGPT、特定の Agent、Skill、ストレージエンジンに依存しません。それらは Project Continuity の契約を支える側であり、プロジェクトを特定のツールに縛るものではありません。
