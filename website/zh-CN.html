项目连续性

Agent 会忘。
项目不该忘。

Agnir 把真正需要延续的项目事实留在项目里：当前状态、下一步、决策和证据。换一个新的 Agent 或执行环境，也能发现这些信息并继续。

项目自己保存的事实

不是又一个记忆黑箱。

Agnir 只保存少量、可发现、需要长期延续的项目事实。它们属于项目，不属于某次聊天、某个模型、某个 IDE 或某种存储方案。

01

当前状态

现在已经确定了什么。

02

下一步

接下来做什么，按什么顺序。

03

决策

以后继续开发时不能丢掉的约束和选择。

04

证据

支持恢复、审查、迁移和对齐的可验证记录。

怎么工作

发现 → 加载 → 工作 → Checkpoint

  1. 发现新的 Agent 从当前项目出发，找到 Agnir 的发现入口。
  2. 加载读取当前连续性，以及这次任务真正需要的状态、下一步、决策和证据。
  3. 工作Agent 正常完成项目工作；Agnir 不接管你的开发流程。
  4. Checkpoint有实质变化时，把新的项目事实整理并写回成一致、可恢复的 Checkpoint。

为跨工具而设计

换 Agent，不换项目。

Agnir Core 不绑定 Git、GitHub、文件系统、ChatGPT、某个具体 Agent、Skill 或存储引擎。它们属于围绕项目连续性构建的 profile、适配器或分发层。
