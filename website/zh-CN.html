先把疑虑说清楚

不用改原来的工作方式

会绑死在某个 Agent 上吗？

不会。Agnir 的连续性属于项目，不属于某个 Agent、模型、聊天或执行环境。

要保存所有聊天记录吗？

不用。Agnir 只留下真正需要跨会话延续的少量项目事实，不把聊天历史当成项目真相。

会接管 Git、IDE 或开发流程吗？

不会。你的工具继续做原来的事；Agnir 只负责让项目状态可发现、可加载、可 Checkpoint。

这是另一个记忆黑箱吗？

不是。下一步、决策和证据都会以可读的 md 文档留在项目里。

最后再讲概念

Agnir 到底是什么？

Agnir 是一个 Project Continuity（项目连续性）协议：把新的 Agent 真正需要的少量项目事实，作为项目自己的持久信息留下来。

01

当前状态

现在已经确定了什么。

02

下一步

接下来做什么，按什么顺序。

03

决策

以后继续开发时不能丢掉的约束和选择。

04

证据

让恢复、审查、迁移和对齐都能被验证的记录。

为跨工具而设计

换 Agent，不换项目。

Agnir Core 不绑定 Git、GitHub、文件系统、ChatGPT、某个具体 Agent、Skill 或存储引擎。它们都围绕项目连续性工作，而不是反过来把项目绑在某个工具上。
