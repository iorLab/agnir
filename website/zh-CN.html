Project-owned truth

不是另一个不可解释的 memory blob。

Agnir 保存一组很小、可发现的 continuity surface。它属于 Project，而不是某个聊天、模型、IDE 或 storage implementation。

01

Current State

现在有哪些 durable truth。

02

Next Actions

还剩什么工作，以及先后顺序。

03

Decisions

未来 Executor 必须保留的约束与决定。

04

Evidence

支持 recovery、audit、migration 与 reconciliation 的 receipts。

如何工作

Discover. Load. Work. Checkpoint.

  1. Discoverfresh Executor 从已授权的 Project 开始，找到 Agnir discovery record。
  2. Load解析 selected continuity，并加载当前任务真正需要的 Project truth。
  3. WorkExecutor 在 Agnir Core 之外完成真正的 Project 工作。
  4. Checkpoint把实质变化 reconciliation 回一个 coherent、durable、Project-owned checkpoint。

Portable by design

换 Executor，不要换 Project。

Agnir Core 对 Git、GitHub、filesystem、ChatGPT、具体 Agent、Skill 与 storage engine 保持中立。这些属于围绕 continuity contract 构建的 profile、adapter 或 distribution concern。
